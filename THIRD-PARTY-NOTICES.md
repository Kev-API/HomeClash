## Removed third-party binaries

### EnableLoopback.exe — **removed 2026-11-25**

- **Former location:** `windows/EnableLoopback.exe` (also `install(FILES ...)` in
  `windows/CMakeLists.txt`)
- **SHA-256:** `0ccf6f4b2f6e89ddb50b3075fd6b604ef7c0d6b13ce377781d898dcd8f9c91d7`
- **Size:** 97,536 bytes
- **Former caller:** `lib/views/config/network.dart`, the "UWP loopback
  exemption" row on Windows, which ran it elevated so UWP / AppContainer apps
  could reach the local proxy port.
- **Embedded version resource (read from the binary itself):**
  - `CompanyName` — Progress Software Corporation
  - `ProductName` / `FileDescription` / `InternalName` — EnableLoopback
  - `ProductVersion` / `FileVersion` / `Assembly Version` — 1.4.3.0
  - `LegalCopyright` — Copyright 2003 - 2020 Progress Software Corporation.
    All rights reserved.
  - `Comments` — Enables Windows AppContainers to make network connections to
    Loopback

**Why it was removed.** It is the EnableLoopback utility that ships with
Telerik Fiddler: proprietary, with no source and no redistribution grant. GPL-3.0
§6 requires corresponding source for binaries a project conveys, and that
obligation cannot be met for this file. Upstream FlClash carries the same file
without a notice; HomeClash does not.

**What was changed.**

| File | Change |
|---|---|
| `windows/EnableLoopback.exe` | deleted |
| `windows/CMakeLists.txt` | dropped the `install(FILES "EnableLoopback.exe" ...)` rule |
| `lib/views/config/network.dart` | removed `LoopbackItem` and its row in `SystemProxySection`; dropped the now-unused `dart:io` and `package:path` imports |

**Effect.** The Windows Settings → Network page no longer offers the UWP
loopback exemption row. UWP / AppContainer apps therefore cannot reach the local
proxy port until a replacement exists.

**Planned replacement.** The utility is a thin wrapper around
`CheckNetIsolation.exe LoopbackExempt` (a signed Windows in-box tool). A
HomeClash-native implementation that shells out to it needs no bundled binary
and can restore the feature without a licensing problem. Tracked in the project
TODO.

## Build- and run-time dependencies

HomeClash's Dart dependencies are pinned in `pubspec.lock`, its Go dependencies
in `core/go.sum`, and its Rust dependencies in `plugins/rust_api/rust/Cargo.lock`.
Those lock files are the authoritative list; the ones worth calling out for
license review are:

| Dependency | License | Note |
|---|---|---|
| `flutter_rust_bridge` | MIT OR Apache-2.0 | FFI codegen |
| `rquickjs` | MIT | MITM script sandbox |
| `ropey` | MIT | text buffer |
| `encoding_rs` | (Apache-2.0 OR MIT) AND BSD-3-Clause | character encoding |
| `interprocess` / `tokio` | MIT | desktop IPC |
| `gvisor` (`with_gvisor` tag) | Apache-2.0 | TUN stack |

Flutter itself, the Dart SDK and the Android/Apple/Windows/Linux platform SDKs
are used under their own terms and are not bundled by this notice.
